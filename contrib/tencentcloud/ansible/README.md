# Ansible: Deploy K8s and Cilium

Deploys a Kubernetes cluster and Cilium in three steps, using the inventory (`hosts.ini`) generated by Terraform.

## Steps

1. **Deploy the K8s cluster**:
   ```bash
   ansible-playbook -i ./hosts.ini ./install_k8s.yaml
   ```

2. **Deploy cilium-operator**:
   ```bash
   ansible-playbook -i ./hosts.ini ./install_cilium_operator.yaml
   ```

3. **Deploy cilium-agent**:
   ```bash
   ansible-playbook -i ./hosts.ini ./install_cilium_agent.yaml
   ```
